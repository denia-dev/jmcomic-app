# JM Reader

简洁、无广告的 JMComic 第三方阅读客户端，iOS 与 Android 双端原生。

> 第三方客户端，与 JMComic 官方无关，仅供学习交流。

## 功能

- 首页推荐、猜你喜欢、搜索（按类型与排序筛选，JM 编号直达）
- 书架：导入自己的漫画与小说（CBZ/ZIP/RAR/PDF/EPUB/TXT），本地阅读器 + 最近阅读
- 小说阅读器：上下滚动 / 左右翻页，EPUB 插图，实时页数，沉浸模式
- 漫画阅读器：上下滚动与横向翻页，下拉过渡切章，图片自动解打乱，下一章预加载
- 登录、云端收藏（多收藏夹）、每日签到、观看历史、阅读统计
- 屏蔽标签与作者，列表自动过滤
- 线路设置：官方域名自动更新，可测速与手动切换

## 安装

在 [Releases](https://github.com/denia-dev/jmcomic-app/releases) 下载最新版附件：

- **iOS**：`JMReader-unsigned.ipa` 用轻松签等工具自签安装（iOS 16+）；或装 `JMReader.mobileconfig` 描述文件，免签名用网页版
- **Android**：`JMReader-Android-v….apk` 直接安装（Android 8.0+）
