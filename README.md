<h1 align="center">JM Reader</h1>

<p align="center">简洁、无广告的 JMComic 第三方阅读客户端<br>iOS 与 Android 双端原生，另有免安装的网页版</p>

<p align="center"><strong>简体中文</strong> | <a href="README.en.md">English</a></p>

> 第三方客户端，与 JMComic 官方无关，仅供学习交流。使用需要 JMComic 账号（请先到官网注册），登录后收藏、历史与官网互通。

## 为什么用它

- **零广告**：没有开屏、横幅和弹窗，打开就是内容
- **双端原生**：iOS（Swift）与 Android（Kotlin）各自原生实现，不是套壳
- **云端同步**：登录后收藏、观看历史跟随账号，多设备互通
- **网页版免安装**：装一个描述文件就能用，iOS 不签名也能看

## 功能

- 首页推荐、猜你喜欢、分类浏览、搜索（类型 / 排序筛选，JM 编号直达）
- 漫画阅读器：上下滚动，点按沉浸，下拉过渡切章，图片打乱自动还原，下一章预加载
- 我的书架：导入本地漫画与小说（CBZ / ZIP / RAR / PDF / EPUB / TXT），本地阅读 + 最近阅读
- 小说阅读器：滚动 / 翻页双模式，EPUB 插图按原位排版，实时页数
- 登录、每日签到、云端收藏（多收藏夹）、观看历史、阅读统计
- 下载离线看
- 屏蔽标签与作者，列表自动过滤
- 线路自动更新，可测速与手动切换

## 下载安装

到 [Releases](https://github.com/denia-dev/jmcomic-app/releases/latest) 下载最新版，一个版本包含全部附件：

| 平台 | 文件 | 装法 |
| --- | --- | --- |
| iOS | `JMReader-unsigned.ipa` | 轻松签等工具自签安装（iOS 16+） |
| iOS（免签） | `JMReader.mobileconfig` | 安装描述文件后，从桌面图标打开网页版 |
| Android | `JMReader-Android-….apk` | 直接安装（Android 8.0+） |

网页版也可以直接在浏览器打开：https://my-modules.peimingliang8.workers.dev/jm/index.html
